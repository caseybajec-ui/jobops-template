# Projects — what the owner has actually built

**This file goes into a model's system prompt.** `apply_packs.py`, `pack_critic.py` and
`prep_pack.py` read it verbatim, alongside `profile.json` and the two generated resumes,
when they write a cover note, judge a pack, or build interview prep. Anything written here
will be stated as fact about you to a recruiter. So it holds only TRUE projects you have
built or are actively building — never a plan, never an aspiration, never a bracketed
placeholder. If a number is not real, cut the clause; the pack writer may not invent one.

**The critic refuses to run when `profile.json` + this file + both resumes total under
8,000 characters.** Thin source material makes every true claim look unsupported, and the
first run of the critic deleted 71 packs for exactly that reason. Write real detail.

The three entries below are for a fictional "Jordan Reyes" so the setup step knows what to
replace. Keep the shape — name, one-line what, stack, outcome with a real number, what it
proves — and replace every word.

---

## Campus textbook marketplace

**What:** a buy/sell site for one university's students, built and run solo for two semesters.
**Stack:** Next.js, Postgres, Stripe Checkout; built with AI-assisted development.
**Outcome:** 1,200 registered students, 3,400 listings, $41K in transactions. **What it
proves:** can take a product from zero to paying users, run payments and support, and
make pricing and policy calls with real money on the line.

## Weekly KPI dashboard for a Series B fintech

**What:** the operating dashboard the COO read every Monday, built during a summer internship.
**Stack:** SQL on the warehouse, a Python refresh job, a Looker front end.
**Outcome:** report prep went from 6 hours to 40 minutes; the pricing memo written from it
led to a two-tier plan. **What it proves:** can turn messy operational data into a decision
an executive acted on, inside someone else's constraints rather than a side project's.

## Delivery pilot recommendation for a regional grocer

**What:** a student consulting engagement; 25 customer interviews and a competitor pricing scan.
**Stack:** interview guide, Excel model, a 12-slide recommendation.
**Outcome:** the client launched the delivery pilot in three stores. **What it proves:**
primary research, segmentation and a recommendation a real client adopted.
